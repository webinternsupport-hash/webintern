================================================================================
                    TROUBLESHOOTING
================================================================================

If tests FAIL, try these fixes:

CHECKBOXES NOT CLICKING:
  → Clear cache: Ctrl+Shift+Delete
  → Hard refresh: Ctrl+Shift+R
  → Check console for errors (F12)
  → Verify CSS file loaded

BUTTONS NOT RESPONDING:
  → Check z-index in DevTools
  → Look for overlay elements
  → Verify click handlers attached
  → Check console for JS errors

CONTENT OVERLAPPING:
  → Check padding-bottom on main
  → Verify bottom nav z-index
  → Look for fixed positioning issues
  → Measure element heights

SCROLLING BROKEN:
  → Check overflow properties
  → Verify height calculations
  → Look for absolute positioning
  → Check transform properties

LAYOUT BROKEN:
  → Clear browser cache
  → Hard refresh page
  → Test in private/incognito mode
  → Try different device
  → Check console for errors
